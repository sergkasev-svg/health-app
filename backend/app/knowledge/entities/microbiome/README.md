# Микробиом: ось кишечник—мышцы

## Roseburia inulinivorans

Сущность и документ используются при запросах про слабость, саркопению, мышечную силу, микробиом, пребиотики, бутират.

- **Карточка сущности:** `roseburia_inulinivorans.json`
- **RAG-документ:** `../documents/gut_2026_roseburia_inulinivorans_muscle_strength.json`

В ответах:
1. Подтягивать сущность через `resolve_medical_context` → `microbiome_context`.
2. Показывать только как перспективное направление; не обещать лечение.
3. Отдельно давать доказанные меры: силовые тренировки, белок, коррекция дефицитов, очная оценка при саркопении.
4. Микробиомные интервенции описывать как экспериментально-перспективные.

Правила формулировок и анти-галлюцинации — в `knowledge/filters/lab_output_guardrails.md` и в промпте `clinical_safety_guardrail_prompt.txt`.
