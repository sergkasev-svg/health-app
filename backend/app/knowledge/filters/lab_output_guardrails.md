# Глобальные правила выдачи по анализам (За Здоровье)

## MASTER v3 — ядро продукта (максимальный уровень)
**Главный справочник:** `app/knowledge/za_zdorovie_MASTER_v3.md`

Содержит:
- **AUTO DIAGNOSIS ENGINE** — правила вида «если маркеры X → гипотеза Y» (связи между маркерами, clinical reasoning).
- **50+ бактерий** по функциям (butyrate/SCFA, barrier/immunity, brain axis, dysbiosis, skin) — готово для RAG, безопасно.
- **100+ маркеров** — органика, кровь, моча, печень, энергия, витамины.
- **30+ сценариев ответа** — AI выбирает готовый клинический сценарий (LOW ENERGY, VITAMIN DEFICIT, OXIDATIVE STRESS, TOXIC LOAD, GUT-BRAIN и др.), а не «думает с нуля».
- **Шаблон вывода:** Pattern → Meaning → Actions → Tests → Safety.

Принцип: analysis → patterns → hypotheses → actions → safety. Система должна связывать системы, давать действия, избегать шума.

## Справочник ОАК / ОАМ / печень и биохимия
Для интерпретации **общего анализа крови (ОАК)**, **лейкоформулы**, **СОЭ**, **общего анализа мочи (ОАМ)** и **базовой биохимии/печени** (ALT, AST, билирубин, ALP, GGT, белок, альбумин) использовать:
- **`app/knowledge/labs/cbc_urine_liver_knowledge_base.md`** — паттерны, объяснения для пациента, следующие шаги, эскалация, шаблоны ответов и безопасные формулировки.

Принцип: анализ → паттерн → смысл → следующий шаг → безопасность. Не ставить окончательный диагноз по одному анализу.

## PRO-слой: микробиом, маркеры, сценарии ответов
Для расширенной интерпретации (микробиом по группам бактерий, органические кислоты и маркеры окислительного стресса/энергии/витаминов/токсической нагрузки, готовые сценарии ENERGY LOW / VITAMIN DEFICIT / OXIDATIVE STRESS / TOXIC LOAD) использовать:
- **`app/knowledge/za_zdorovie_pro_knowledge_base.md`** — RAG-база, расширение промптов, слой интерпретации. Принцип: analysis → pattern → meaning → action → safety.

## НЕЛЬЗЯ
- Выдавать более **3 гипотез** пользователю.
- Добавлять болезни **без связи с анализами** (например малярия, сепсис, COVID при обычном CBC без симптомов).
- Давать **редкие диагнозы без симптомов** (менингит, инсульт, инфаркт и т.п. только при соответствующей клинике).

## Порядок в конвейере Михаила
1. **Сначала:** анализ лаборатории + применение primary rules (thyroid, anemia, allergy).
2. **Потом:** secondary rules (NLR, SII, SIRI, AISI, ITI) — только если нет явного диагноза или confidence < 0.6.
3. **Потом:** фильтр гипотез (`is_relevant_diagnosis` / `filter_ranked_hypotheses_for_labs_only`).
4. **Только после этого:** генерация ответа пользователю.

## Стоп-лист диагнозов (HARDBLOCK)
Не показывать пользователю как гипотезу из изолированного анализа:
малярия, сепсис, covid, импетиго, отит, инсомния.

## Микробиом: ось кишечник—мышцы (Roseburia inulinivorans)

### Шаблон вывода для R. inulinivorans
При упоминании Roseburia inulinivorans в ответе использовать формулировку:

**R. inulinivorans** — перспективный маркёр/кандидатный микроб оси «кишечник—мышцы».
Текущее состояние доказательств:
- у людей: ассоциация с большей мышечной силой;
- у животных: есть данные, поддерживающие причинную роль;
- в клинической практике: пока не стандарт лечения и не подтверждённый терапевтический пробиотик.

### microbiome_claim_guardrails
Для сущностей с уровнем доказательств «human association + animal causal support» (в т.ч. R. inulinivorans):

**Разрешённые формулировки:**
- «ассоциирована с»
- «может быть связана с»
- «перспективный кандидат»
- «требуются клинические испытания у людей»

**Запрещённые формулировки:**
- «лечит саркопению»
- «доказанно повышает силу у людей»
- «назначить как терапию»

**Не использовать в медицинской части продукта:**
- фразу «кишечная бактерия, дающая силу»;
- «открывает перспективу использования для коррекции саркопении» — только как исследовательская гипотеза, не как практическая рекомендация;
- стимуляцию R. inulinivorans фруктанами подавать осторожно: биологически правдоподобно (Roseburia — ферментаторы подобных субстратов), но не как клинический протокол «ешь X — вырастет Y».

## Микробиом: единая безопасная формула по всем осям

По всем направлениям (кишечник→мышцы, кишечник→мозг, кишечник→иммунитет, кишечник→кожа) использовать только формулировки:

**Разрешено:** «связано» / «ассоциировано» / «перспективно» / «исследуется» / «не заменяет стандартное лечение».

**Особенно строго** для депрессии, тревоги, саркопении, иммунных и кожных заболеваний: даже хорошие РКИ и механистические данные не равны готовому клиническому стандарту.

**Психобиотики (ось кишечник—мозг):** модель должна уметь говорить не только «есть перспективные данные», но и «результаты по психобиотикам смешанные» (есть и отрицательные исследования, например комбинации Lactobacillus helveticus + B. longum при low mood).
