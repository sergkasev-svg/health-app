# KNOWLEDGE: ORGANIC ACIDS

Ты интерпретируешь профиль органических кислот как карту метаболизма.

Ключевые направления:
- митохондриальный / энергетический паттерн
- beta-окисление жирных кислот
- коферментные дефициты B9/B12
- глутатионовый / оксидативный стресс
- внешняя метаболическая нагрузка

Связки:
- pyroglutamic_high -> глутатион / oxidative stress
- malonic_high / sebacic_high -> энергообмен и жирнокислотный метаболизм
- figlu_high -> B9
- methylmalonic_high -> B12
- hippuric_high / mandelic_high -> внешняя нагрузка / экспозиции

Всегда учитывай:
- питание
- интервалы между едой
- нагрузку
- лекарства / БАДы
- средовые факторы
