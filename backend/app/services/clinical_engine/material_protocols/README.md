# Методичка: material-first маршрутизация

## Цепочка

`document → route_document() → report_type → движок отчёта`

Устаревшее без материала: «угадывание профиля» → коллизии (моча ↔ ОАК).

## Правило

**Material > Profile**: сначала биоматериал, затем подтип анализа.

## Биоматериалы (рынок)

| Уровень | Материалы |
|--------|-----------|
| CORE | Кровь (CBC, биохимия, липиды, гормоны, коагуляция, витамины), Моча (ОАМ, суточная, микроальбумин, ОК в моче), Кал (копрограмма, скрытая кровь, паразиты) |
| IMPORTANT | Слюна (кортизол, ДНК), Мазки (урогенитал, ЛОР, ПЦР), Сперма, Ликвор |
| ADVANCED | Биопсия/гистология, Серология, Генетика |

## Кровь: приоритет ОАК (CBC)

Если `detect_cbc` (≥3 маркера в тексте/значениях) — **всегда** `cbc` / `cbc_with_reticulocytes`,  
не липидный и не общая биохимия, даже при наличии других слов.

## Запреты

- `urine` → не `cbc`, не `lipid_panel`
- `blood` → не `urinalysis`

## API

- `route_document(text, lab_values?)` → `MaterialRoutingResult`
- `detect_report_type` в `document_type_detector` сначала вызывает `route_document`, при `unknown` — legacy.

## Промпт для LLM / Cursor

При классификации документа: 1) определи биоматериал по якорям (биоматериал:, моча, кровь, кал, слюна, мазок); 2) внутри крови проверь ОАК до липидов; 3) не смешивай маркеры ОАМ (pH, плотность, нитриты) с профилем крови.
